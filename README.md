# A556EXXUIEZJ1

Exynos 8845 (S5E8845) kernel workspace: `kernel/`, `projects/`, `prebuilts/`, `WORKSPACE`.

`prebuilts/` is stored in Git LFS.

## Clone

Install Git LFS first:

```sh
git lfs install
```

Then clone:

```sh
git clone https://github.com/minhmc2007/A556EXXUIEZJ1.git
cd A556EXXUIEZJ1
```

Already cloned without LFS? Fetch the real files:

```sh
git lfs install
git lfs pull
```
